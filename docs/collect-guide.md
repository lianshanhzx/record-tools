# 采集工具使用指南（测试人员）

> [返回项目首页](../README.md) · [查看采集功能说明](./collect.md)

## 1. 开始采集

1. 打开需要测试的业务页面，确认页面加载完成。
2. 点击浏览器工具栏中的插件图标。
3. 若出现模式选择页，选择「采集工具」。
4. 页面右上角出现红色「采集中」标记后，即表示采集已开始。

## 2. 执行测试

按正常业务流程操作页面即可。插件会自动采集常见操作，包括：

- 点击按钮；
- 输入内容；
- 选择下拉框、日期、单选框、复选框和树形节点；
- 在弹窗、页签、iframe 或跳转后的页面中继续操作。
- 页面跳转、刷新后会自动续采，无需再次点击插件图标。

建议一次采集只覆盖一个完整的原子化功能业务场景，例如“客户查询”或“新增客户”。

## 3. 结束采集

完成一个完整业务场景后，点击右上角「采集中」标记中的「结束」，再根据实际结果选择。**该选择会决定本次数据是否保留，以及后续如何被使用，请勿随意选择。**

| 选择 | 何时选择 | 对采集数据的影响 |
| --- | --- | --- |
| **通过** | 测试场景按预期完成，例如查询、保存、提交及结果展示均正常。 | 保存并下载 JSON 数据，结果标记为“通过”。该数据可作为正常业务流程的有效样本使用。 |
| **不通过** | 测试过程中发现业务异常、页面报错、接口失败、无法提交或结果与预期不符，但已执行的操作过程仍有分析价值。 | 保存并下载 JSON 数据，结果标记为“不通过”。后续可结合操作过程定位异常或作为失败场景样本使用。 |
| **废弃** | 误开始采集、操作了错误的业务对象、场景未完整执行，或本次过程与测试目标无关。 | 直接丢弃本次数据，不下载、不保存，后续无法恢复。 |

选择「通过」或「不通过」后，浏览器会自动下载 JSON 文件到默认下载目录；请按测试任务要求保留或提交该文件。若无法判断本次场景是否有效，优先选择「不通过」保留数据，避免丢失可能有价值的异常操作过程。

## 4. 注意事项

- 尽量避免点击与当前场景无关的控件或页面空白区域。
- 需要等待查询、保存或提交结果返回后，再继续下一步操作。
- 悬浮标记遮挡页面时可以拖动。
- 如误采集且数据无价值，结束时选择「废弃」。
